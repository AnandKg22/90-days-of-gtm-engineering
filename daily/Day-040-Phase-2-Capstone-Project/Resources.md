# Resources - Day 040: GTM Automation References

This document compiles technical resources, documentation links, and guides for developing GTM platforms, setting up SQLite databases, and managing CRM APIs.

---

## 🛠️ Web App & Backend Servers
- [Flask Official Documentation](https://flask.palletsprojects.com/) — Guide to creating routes, serving templates, and setting up API endpoints in Python.
- [SQLite Documentation & Tutorial](https://www.sqlite.org/index.html) — Standard, serverless SQL database engine integrated into Python.
- [FastAPI Documentation](https://fastapi.tiangolo.com/) — High-performance alternative Python framework for building RESTful GTM APIs.

## 🔗 CRM & Outbound APIs
- [HubSpot Developer Portal](https://developers.hubspot.com/) — Documentation for Contact, Company, and Deal CRM Object APIs.
- [Salesforce Developer API Guides](https://developer.salesforce.com/docs) — Learn REST, Bulk, and Composite API integration structures.
- [SendGrid v3 API Reference](https://docs.sendgrid.com/api-reference/whats-new) — Outbound email delivery configurations and templates.
