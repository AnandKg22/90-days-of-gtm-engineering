# Resources - Day 043: Agent & Workflow Orchestration

This document compiles documentation links, tutorials, and articles on workflow engines, task queue architectures, and distributed transactions.

---

## 🛠️ Production Workflow Engines
- [Temporal.io Documentation](https://docs.temporal.io/) — A developer-first platform for orchestrating stateful, long-running, and highly reliable workflows.
- [Apache Airflow](https://airflow.apache.org/) — Popular open-source platform to programmatically author, schedule, and monitor workflows as DAGs.
- [Prefect Core](https://docs.prefect.io/) — Modern python-native orchestrator for data flows and tasks dependencies.

---

## ⚙️ Task Queues & Workers
- [Celery Python Framework](https://docs.celeryq.dev/) — Asynchronous task queue/job queue based on distributed message passing.
- [BullMQ (Node.js)](https://docs.bullmq.io/) — Fast, robust Redis-based message queue for Node.js environments.

---

## 📚 Distributed Systems & Saga Patterns
- [Microservices.io: Saga Pattern](https://microservices.io/patterns/data/saga.html) — Clear architectural breakdown of Saga patterns and compensation transaction structures.
- [Microsoft Architecture Guide: Saga Distributed Transactions](https://learn.microsoft.com/en-us/azure/architecture/reference-architectures/saga/saga) — Enterprise Saga orchestration blueprints and guidelines.
