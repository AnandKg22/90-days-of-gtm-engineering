# Resources - Day 042: Model Context Protocol (MCP)

This document lists documentation links, SDK repositories, registries, and tutorials for the Model Context Protocol (MCP).

---

## 🔗 Official MCP Documentation & Specs
- [Model Context Protocol (MCP) Official Site](https://modelcontextprotocol.io/) — Anthropic's home page for the protocol, specs, and quickstarts.
- [MCP Specification Reference](https://modelcontextprotocol.io/docs/concepts/architecture) — In-depth architectural details, client-server models, and RPC schemas.
- [Claude Desktop MCP Integration Guide](https://modelcontextprotocol.io/docs/tools/claude-desktop) — Step-by-step instructions on connecting local and remote servers to Claude.

---

## 🛠️ MCP SDKs & Libraries
- [Official Python MCP SDK](https://github.com/modelcontextprotocol/python-sdk) — Anthropic's official Python library for constructing clients and servers.
- [Official TypeScript/JS MCP SDK](https://github.com/modelcontextprotocol/typescript-sdk) — Node.js library for building MCP services.

---

## 📦 MCP Servers Registries & Examples
- [GitHub: Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers) — Curated collection of open-source MCP servers (filesystem, Postgres, GitHub, SQLite, Google Search, etc.).
- [Anthropic Quickstart Servers](https://github.com/modelcontextprotocol/servers) — Reference server implementations for filesystem and SQLite integrations.
