# Resources - Day 047: AI Proposal Generation

This document lists reference links, document compilers, electronic signature APIs, and CPQ platforms.

---

## 📄 Document Compilers & Templating Engines
- [Pandoc Document Converter](https://pandoc.org/) — Command-line tool to convert files from one markup format to another (Markdown to PDF/DOCX).
- [WeasyPrint PDF Engine](https://weasyprint.org/) — Visual rendering engine for HTML and CSS that exports to PDF documents.
- [Python-docx Library](https://python-docx.readthedocs.io/) — Python library for creating and updating Microsoft Word (.docx) files.

---

## 🖊️ Electronic Signature APIs
- [DocuSign Developer Center](https://developers.docusign.com/) — Integrate document signature requests, templates, and webhook tracking events.
- [Dropbox Sign API (HelloSign)](https://www.hellosign.com/api) — Simple signature request API integrations for sales contracts.

---

## 💰 CPQ & Billing Systems
- [Salesforce CPQ & Billing](https://www.salesforce.com/products/cpq/) — Enterprise platform for configuring quotes, pricing rules, and generating contracts.
- [HubSpot Quotes API](https://developers.hubspot.com/docs/api/crm/quotes) — Simple API endpoints for generating and tracking deals and quotes.
