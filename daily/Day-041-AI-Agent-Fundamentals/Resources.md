# Resources - Day 041: AI Agent Fundamentals

This document compiles reading materials, research papers, framework libraries, and guides on AI agent loops, reasoning paradigms, and function calling.

---

## 📄 Academic Research Papers
- [ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)](https://arxiv.org/abs/2210.03629) — The foundational paper detailing the Thought-Action-Observation loop paradigm.
- [Chain-of-Thought Prompting Elicits Reasoning in Large Language Models (Wei et al., 2022)](https://arxiv.org/abs/2201.11903) — Groundwork paper explaining step-by-step reasoning in LLMs.
- [Self-Refine: Iterative Refinement with Self-Feedback (Madaan et al., 2023)](https://arxiv.org/abs/2303.17651) — Techniques for agents to critique and improve their own output.

---

## 🛠️ Agent Frameworks & Libraries
- [LangChain Agents documentation](https://python.langchain.com/docs/modules/agents/) — Guide to building ReAct agents, custom tools, and execution loops.
- [CrewAI Framework](https://www.crewai.com/) — Role-playing multi-agent systems for orchestrating complex business processes.
- [Microsoft AutoGen](https://microsoft.github.io/autogen/) — Framework for multi-agent conversations and tool integrations.

---

## ⚙️ Function Calling & Tool Binding Guides
- [OpenAI Function Calling Guide](https://platform.openai.com/docs/guides/function-calling) — How to construct JSON schemas and parse function arguments.
- [Google Gemini API Function Calling](https://ai.google.dev/gemini-api/docs/function-calling) — Connect Gemini models to external APIs and databases.
