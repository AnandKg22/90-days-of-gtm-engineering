# Resources - Day 044: AI Research Agents

This document lists documentation links, libraries, API developer portals, and guides for web scraping, firmographic crawling, and data enrichment.

---

## 🛠️ Web Scraping Libraries (Python & JS)
- [BeautifulSoup4 Documentation](https://www.crummy.com/software/BeautifulSoup/bs4/doc/) — Python library for pulling data out of HTML and XML files.
- [Scrapy Framework](https://scrapy.org/) — Collaborative web crawling framework for extracting data from websites.
- [Playwright for Python](https://playwright.dev/python/) — Reliable end-to-end testing and web scraping library for dynamic Javascript-rendered applications.

---

## ⚙️ Technographic & Enrichment APIs
- [BuiltWith Developer API](https://api.builtwith.com/) — Query technographic databases to discover what technologies are used on specific domains.
- [Crunchbase API Gateway](https://developer.crunchbase.com/) — Access public funding rounds, employee counts, and corporate news datasets.
- [Hunter.io Domain Search API](https://hunter.io/api) — Find email formats and decision-maker contact lists.
- [Clearbit Enrichment API Docs](https://dashboard.clearbit.com/docs) — Real-time company firmographic and technographic data matching.
