# Resources - Day 049: AI Knowledge Assistants

This document compiles reference links, developer guides, vector databases, and indexing frameworks for RAG systems.

---

## 🗄️ Vector Databases
- [ChromaDB Documentation](https://docs.trychroma.com/) — Open-source embedding database for AI applications.
- [Pinecone Vector DB](https://docs.pinecone.io/) — Managed vector database for high-performance semantic search.
- [PGVector PostgreSQL Extension](https://github.com/pgvector/pgvector) — Vector similarity search extension for PostgreSQL.
- [Qdrant Vector Search Engine](https://qdrant.tech/) — Vector similarity search engine with an easy-to-use API.

---

## 🛠️ Indexing & RAG Orchestrator Frameworks
- [LlamaIndex Documentation](https://docs.llamaindex.ai/) — Data framework for connecting custom data sources to private LLMs.
- [LangChain python docs](https://python.langchain.com/) — Framework for building applications with LLMs, agents, and retrieval chains.
- [Tiktoken Tokenizer (OpenAI)](https://github.com/openai/tiktoken) — Fast BPE tokenizer used to calculate token counts for chunking.
